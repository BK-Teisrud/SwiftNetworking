# Instruksjoner for arbeid i dette repositoryet

- Ikke opprett eller legg inn analyserapporter, kodegjennomgangsrapporter, funnlister eller midlertidige vurderingsdokumenter i repositoryet. Dette gjelder også ignorerte filer og genererte DocC-guider.
- Del analyser, vurderinger, anbefalinger og funn direkte i samtalen med brukeren. Opprett bare slike rapportfiler dersom brukeren uttrykkelig endrer denne regelen.
- Behold og vedlikehold produktdokumentasjon, API-referanse, arkitekturbeskrivelse, bruksveiledninger og CHANGELOG. Disse skal beskrive pakken og gjeldende kontrakter, ikke lagre analysehistorikk.
- Utviklingsverktøy skal være skrevet i Swift. Bruk Tools/RepositoryTools.swift og oppdater sentrale artikler i Docs før DocC-guidene synkroniseres.
